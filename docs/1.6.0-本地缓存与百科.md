# 栖读 1.6.0：本地缓存与百科

## 使用

1. 在作品的「下载方案」里点击解析结果，或粘贴网页、网盘分享链接、磁链。应用继续读取中转页，网盘会尝试自动填写提取码、选择文件并进入网页下载步骤。
2. 资源卡片出现具体文件后点击「加载到本地」。TXT、EPUB、PDF 下载完成会绑定这本作品；原作品的收藏、书评、阅读进度和书单保持原有记录。
3. 从书架或收藏点击作品即可阅读本地文件，无需再查找链接。详情页与「偏好设置 → 本地阅读缓存」可以清空对应文件。清空后仍能从原作品重新加载。
4. 在本地详情或在线作品详情展开「百科概述」。支持百度百科、维基百科，正文、来源和获取日期直接展示。可以调整查询关键词、切换同名词条或刷新概述。

## 数据行为

- 下载的正文只在应用资料目录 `book-downloads` 中保存一份，书架记录关联 UUID 文件。清空缓存会删除该文件及其任务记录；完整备份仍包含已加载的正文。
- 恢复备份后使用备份内的正文，不再引用原机器的文件 ID。清空恢复的缓存也会删除其正文。
- 同一地址用于不同作品时分别保存文件，删除一本的缓存不会破坏另一本。
- 网盘取得的原生下载保持 POST、Cookie 和临时票据上下文，准备完成后暂停；用户选择加载才进入队列。临时票据十分钟后失效，重新解析即可。
- 成功的百科查询缓存在本机七天，最多五十组；「更新概述」主动刷新。来源受限或词条不存在会显示状态，公开索引摘要单独标注。

## 检查与边界

- 105 项单元测试通过，覆盖多层入口与循环、作品绑定、完整备份、暂停与恢复下载、重复关闭、文件隔离、百科解析和失败回退。
- 桌面自动化：下载流程 11 项、网盘与磁链 14 项、搜索登录会话 10 项、搜索与收藏 8 项通过。
- Windows 打包版基础检查 6 项通过，覆盖 ASAR 启动、隔离、最小窗口、PDF 和 EPUB；开发版与最终打包版的完整缓存流程各 8 项通过，包括提取码、真实 POST 下载、磁盘文件删除、离线重启、取消后重试与登录续接。
- 2026-10-26 在真实 Electron 会话内已获取《红楼梦》的百度百科与维基百科概述，并在应用详情里显示；百度百科有时先返回验证脚本。Bing 公开索引本次曾返回无关或空结果，应用会过滤这些结果。
- 网盘完整流程使用受控 HTTP 分享页面验证，包含提取码、HttpOnly Cookie、POST 票据、原生 DownloadItem 和真实磁盘传输。没有用用户的真实百度网盘账号或实际分享文件验证，无法保证每一种网盘页面均能自动完成。登录、验证码或仅客户端下载的入口仍需用户处理。
- ZIP、RAR、7Z 支持解析、筛选、下载和另存；尚不自动解密、解压内部文件。

百科接口参考：[MediaWiki PCS](https://www.mediawiki.org/wiki/Page_Content_Service)、[MediaWiki 搜索 API](https://www.mediawiki.org/wiki/API:Search)。

# 栖读 1.7.0

## 使用变化

- 页面右上角提供日间/夜间切换，书架与阅读界面均可使用。切换同步修改阅读主题，重启后保留。
- 下载 ZIP、RAR、7Z 后自动解压并关联原作品。匹配文件名优先，随后优先 EPUB、TXT、PDF，说明文件靠后；支持四层嵌套。原作品的收藏、书评、进度继续保留。
- 已完成的下载提供「立即阅读」，无需先返回书架。加密包可填写解压密码后点击「解压并阅读」；失败保留原资源，成功后用解压文件替换。
- TXT 支持正文前缀、间隔数字、全角数字、中文数字、英文 Chapter/Part/Book、番外以及成组编号标题。HTML、Markdown 按正文标题分章。
- EPUB 优先使用内置目录，缺失时按阅读顺序生成目录，并在后台补充章节标题。PDF 优先使用内置书签目录，没有目录时后台识别各页的章标题。扫描 PDF 没有可用文字时保留页码导航，不提供 OCR。

## 文件与兼容性

解压组件为未修改的 7-Zip 26.05，随包包含 `7z.exe`、`7z.dll`、许可证、来源哈希和对应源码。安装包来自[上游发布](https://github.com/ip7z/7zip/releases/tag/26.05)，[官方下载页](https://www.7-zip.org/download.html)提供该发行版本的入口。

只把选中的归档成员写入应用私有 UUID 文件，不按归档路径写入磁盘。校验展开大小、文件数量、路径、文件格式与 EPUB 结构，损坏或密码错误时不替换书籍。原压缩包在成功后移除；缓存清理删除解压出的书籍文件。重新加载保留原压缩包下载地址与格式。

单个输出文件上限 100 MB，归档总展开大小上限 512 MB，条目上限 2000，嵌套上限四层。文件名无法匹配时按格式与大小自动选择；含多本书的合集应核对任务中显示的实际文件名。

## 验证范围

单元测试包含真实 ZIP、RAR、7Z 解压，嵌套包、加密包重试、危险路径拒绝、失败保留原文件、资源替换和重启，以及章节识别与 HTML 分章。

桌面流程检查右上角主题切换，三种压缩包自动替换同一作品，直接阅读、TXT 章节跳转，夜间和进度重启恢复，密码重试，无目录 EPUB，PDF 内置目录与正文识别，清空解压缓存。全部测试使用自行生成的文件与隔离资料目录。

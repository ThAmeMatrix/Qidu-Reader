# 在线找书与站点适配

栖读 1.2.0 在「发现好书」中提供书名/作者搜索、站点筛选、分页和书籍详情。结果可以加入本地书架、收藏和写书评。爱心再次点击即可取消收藏；取消收藏不删除书评，彻底移除请使用书籍详情的「移出书架」。

1.2.0 新增番茄小说与刺猬猫阅读。旧版升级时自动添加这两个新源一次；之后删除不会在重启或恢复备份时被补回。原有站点的自定义接口、解析规则、启停选择与删除记录继续保留。达到 50 个站点上限时，可腾出位置后使用「补回内置站点」。

直接搜索通过 Chromium 与站点窗口使用同一份会话，登录跳转和分页也会继续携带会话。需要网站脚本完成认证的站点可自动加载网页并解析结果；旧版未修改的内置搜索配置会自动升级。

书架中的在线书籍保存元数据和来源链接，打开后显示详情；「前往原站」在隔离的站点窗口中阅读。此版本不批量下载小说正文。

## 内置站点

2026-10-23 的公开网络检查及本版适配依据如下。需要账号的真实结果未代用户登录验证；站点状态可能随网络、登录状态和网站改版变化。

| 站点 | 接入方式 | 本次实测 |

| [起点中文网](https://www.qidian.com/) | `/search?kw=…&page=…`；直接读取与网页加载 | 匿名请求返回 HTTP 202 验证页；验证后可使用同一会话重试 |
| [纵横中文网](https://www.zongheng.com/) | 网页自身使用的公开搜索 JSON、HTML 结果与详情解析 | 「剑」首、次页各 20 本且内容不同；详情成功读取书名、作者、简介、封面 |

| [Novelia](https://n.novelia.cc/) | 已修正为 `/api/novel`，接口页码从 0 开始；网页 `/novel` 页码从 1 开始 | 官网公开前端代码确认 API、参数和 `items/pageNumber` 返回结构；匿名接口拒绝访问，默认通过网页自身认证后自动读取 |

| [刺猬猫阅读](https://www.ciweimao.com/) | 首页搜索框公布的 `/get-search-book-list/0-0-0-0-0-0/全部/关键词/页码`；结果卡片与 `rel=next` 分页 | 匿名查询「魔女」首、次页各 10 本，第二页有 9 本新增（榜单排序可能变动）；书名、作者、简介、封面和详情均成功解析 |

番茄的网页书卡使用点击事件而非普通链接。桌面端只读取官网已经发出的书目搜索响应，提取书名、书号、作者、简介、封面和分类，不读取请求凭证。接口直读可正常分页；自动网页加载后的后续页，需要在站点窗口翻页后点击「读取搜索结果」。若下一页接口失败，不会用第一页内容冒充下一页。官网自身在接口失败时也可能显示“没有搜索到”，栖读仅在有效成功响应明确返回空列表时提示无结果。

优书的「搜索公开网页」在站点窗口打开 Bing 的 `site:youshu.me/book/ 关键词` 查询，查找搜索引擎已收录的公开书页。它不是站内全量搜索，结果可能不完整或过期；打开其中的书籍详情后可点击「读取书籍详情」带回栖读。此入口不改变优书原搜索配置，也不提供登录权限绕过。

登录、验证页面不会被标为「零搜索结果」，搜索跳回首页时也不会把推荐列表当作查询结果。登录、验证仍由用户在原站完成。认证由 Chromium 和网站自身处理；应用不会索取或提取账号密码、访问令牌。会话复用、网页自行认证、分页及重启恢复使用独立本地测试站完成验证。

## 使用站点窗口

1. 搜索结果旁点击「站点窗口」，或提示中的「登录站点／前往验证」。
2. 在原站正常搜索；如有需要，自行登录或完成验证。
3. 完成后点击「登录完成，重试」。栖读会使用该会话重新执行原搜索，后续搜索无需每次手动读取。
4. 如果希望直接带回原站当前页，也可点击「读取搜索结果」。栖读会把识别的书目展示成卡片。
5. 若在书籍详情页，点击「读取书籍详情」。
6. 遇到空白页可点击「主页」，从原站搜索框重新搜索。部分站点仍可能暂时不可用，应用会保留这一状态。

站点窗口与本地书架隔离。网页无法调用栖读的文件、书架或窗口接口。登录状态保存在单独的 Electron 会话中；主应用仅接收当前页面的文本和元数据，不执行抓取到的脚本。

## 添加自定义网站

进入「管理搜索站点 → 添加搜索网站」，填写名称、主页和搜索地址。例如：

```text
主页：https://example.com/
搜索地址：https://example.com/search?q={query}&page={page}
请求方式：GET
```

`{query}` 会替换为编码后的搜索词，`{page}` 从 1 开始，`{page0}` 从 0 开始。POST 搜索可将 `searchkey={query}&page={page}` 填入表单参数。直接请求表单以 UTF-8 编码发送；网页加载方式从原站提交搜索表单并保留其隐藏字段。响应文字支持自动识别、UTF-8、GBK/GB18030。

「搜索加载方式」支持直接读取、自动和加载动态网页。自动方式会先读取接口，在接口需要动态加载或网页认证时打开隐藏的隔离网页并等待结果。接口与用户可见搜索页不相同时，填写「站点窗口搜索地址」，例如接口使用 `/api/novel?page={page0}`，网页使用 `/novel?page={page}`。此项能力需要桌面版；浏览器开发预览不能使用桌面登录会话。

默认识别常见 `/book/`、`/novel/`、`/info/`、`/detail/` 链接。非标准结构可在「高级解析规则」填写 CSS 选择器：

| 字段 | 示例 |
| --- | --- |
| 结果条目 | `.result-item` |
| 书名 | `h3` |
| 详情链接 | `h3 a` |
| 作者 | `.author` |
| 封面图片 | `img` |
| 简介 | `.intro` |
| 下一页链接 | `a.next` |

字段相对于单条结果，下一页相对于整个文档；`:scope` 指条目本身。配置后可填写关键词点击「测试解析」，确认识别数量与书名再保存。规则只接受 CSS，不支持自定义 JavaScript。未匹配到结构的页面会明确提示，可调整规则或打开原站。

站点最多保存 50 个，支持 JSON 配置导入/导出。完整 `.qidu` 备份包含站点、在线书目、收藏和搜索历史，并兼容旧版备份。网站会话由 Chromium 保存在本机，不包含在书架备份或站点配置中。

## 验证

`pnpm test:discovery` 使用独立应用资料目录，验证收藏取消、书签取消、站点配置、自定义搜索、分页、过期响应丢弃、原站窗口隔离、动态页面读回和重启保存。`pnpm check:sources` 会匿名直连八个原站接口，并在 `test-results/sources-*/report.json` 留下状态；它不使用桌面会话或网页加载，不能代表已登录桌面搜索的结果，也不属于默认离线单元测试。

`pnpm test:search-session` 使用本地 HTTP 测试站，验证登录提示、站点窗口登录后重试、HttpOnly 会话复用、网页自身认证、POST 表单上下文、搜索跳回首页、会话重启保存和不安全跳转拦截。该测试不访问实际站点账号。

`pnpm test:new-sources` 将站点 HTTPS 页面替换为离线样例，验证番茄动态卡片、手动分页、响应字段筛选、空响应与真实空结果的区别、优书公开索引按钮、新源删除及启停保存；不访问用户账号或真实搜索引擎。

## 1.7.0：自动解压与直接阅读

ZIP、RAR、7Z 通过「加载到本地」下载完成后，自动提取内部的 TXT、EPUB、PDF 并替换对应作品资源。优先选择文件名匹配作品名称的书籍，再优先 EPUB、TXT、PDF，降低说明文件优先级。支持最多四层压缩嵌套；加密包失败时保留原文件和原作品，可在任务中填「解压密码」后点「解压并阅读」。解压密码与网盘提取码分别处理。

下载任务提供「立即阅读」；已完成的下载结果也可点击直接阅读。成功解压后移除原压缩包，另存功能保存当前解压出的文件。失败不会替换原作品。清空缓存会删除解压出的正文，同时保留书评、收藏、进度。

解压组件随程序附带（7-Zip 26.05），无需安装其他软件。单个解压文件不超过 100 MB，归档条目不超过 2000，总展开大小不超过 512 MB。拒绝路径穿越、链接与重复路径，只提取选中的文件，不执行归档内容。

## 1.6.0：解析到文件、作品缓存与百科

- 点击「解析下载」后，自动跟随中转入口，最多 12 页、5 层，循环链接只检查一次。未解决的入口仍可查看和重试。
- 网盘会自动尝试提取码、文件选择、普通下载或浏览器下载；取得具体文件时暂停传输并在资源卡片显示名称。点击「加载到本地」才加入下载任务。临时下载票据保留 10 分钟，过期后重新解析。涉及登录或验证码时在应用内网盘窗口完成，随后继续；并不保证所有网盘页面都能无人操作完成。
- TXT / EPUB / PDF 下载完成自动关联当前作品，保留原收藏、书评、阅读位置和书架身份。点击收藏作品直接读取本地文件；不重复保存一份正文到 IndexedDB。
- 详情和偏好设置提供「清空缓存」。它实际删除该作品关联的下载文件和缓存记录，保留作品资料、收藏、书评、进度。下载任务中的清理按钮同步更新作品缓存状态。之后可以重新解析加载。
- ZIP / RAR / 7Z 继续支持识别、筛选、下载和另存，需要解压后导入内部书籍；目前不自动解密或解压压缩包。
- 本地备份包含已加载的书籍内容，恢复时去掉原机器的下载 ID；可继续离线阅读，清空缓存也会删除这份恢复的内容。
- 作品详情的「百科概述」展示百度百科、维基百科的来源文字，支持修改查询词。百度百科失败时尝试公开搜索索引并标注摘要来源，维基百科使用 PCS summary / Action API。成功结果缓存七天，可点「更新概述」刷新。

# 站内查找与下载（1.5.1）

在发现页书籍卡片点击「下载方案」，或在在线/本地详情点击「查找下载方案」。书名与作者自动填入，默认按书名搜索；需要更精确时勾选「同时匹配作者」。繁简体、译名及作者转写会影响匹配，可以修改后重新查找。

## 在当前界面完成下载

1. 启用的来源以最多三个并行请求检索，结果按来源展示，可切换「全部来源」或单个站点。
2. 点击书名、「检查文件」或「解析下载」，在结果卡片中查看页面摘要及文件列表。中转下载页继续在卡片内读取，支持返回上一层；也可粘贴网页或文件地址，点击「在此读取」。
3. 选择 EPUB、PDF、TXT 或 ZIP、RAR、7Z 文件，下载会保存到应用本地缓存，不打开系统浏览器。显示字节数和进度，支持取消与重新下载。
4. 下载完成后点击「加入书架」，即使用现有阅读器离线阅读；重复文件不会重复入架。「另存文件」可自行选择保存位置。
5. 右上角「下载」管理全部任务。清理仅删除下载缓存和记录，已加入书架的书籍不受影响。

格式栏提供「压缩包」汇总筛选和 ZIP、RAR、7Z 单格式筛选，作用于网页文件、网盘读回文件与磁链文件列表。格式按钮筛选已经读取的文件；点击「重新查找」后，所选格式也会用于搜索引擎关键词。目录类来源按书名和选中的作者查找。

## 来源与解析

| 来源 | 站内处理方式 |
| --- | --- |
| Internet Archive | 搜索文本类书目、分页、读取元数据中的公开文件和大小；受限/借阅记录不列出下载按钮 |
| Project Gutenberg | 解析搜索目录与书目页实际提供的 EPUB、PDF、TXT 链接 |
| 必应、百度、Google | 读取搜索结果标题、摘要与链接，过滤不匹配书名的结果；必要时使用应用内隐藏网页加载动态内容 |
| Standard Ebooks | 解析书名、作者和书目页的 EPUB 下载链接 |
| 书格 | 解析书目结果，继续读取下载中转页；网盘是否能提供文件取决于当前访问条件 |
| 中文维基文库 | 解析搜索结果、作品页及导出入口；验证或访问限制会显示状态 |
| 自定义站点 | 自动识别常见结果结构，也可配置 CSS 选择器并预览实际解析结果 |
| 书籍原页/手动链接 | 在当前界面读取摘要、文件和后续下载入口 |

「候选」不代表已经确认整本文件。下载前解析实际链接，下载过程中核验响应和文件内容；不会根据书名拼造下载文件。无扩展名的下载接口和中转重定向也可依据响应类型、文件名识别。需要登录、验证码、借阅或站点未提供文件时，会保留明确状态，不把网页保存为电子书。

搜索引擎和下载网站的结果依赖原站与当前网络状态。通用解析不能保证取得所有网站的文件。网盘可以进入应用内窗口操作，浏览器实际触发的下载会接入队列；只提供外部客户端下载、加密包或权限受限的资源仍可能无法取得文件。可调整关键词、切换来源，或使用自定义解析规则。书目可能是同名作品、其他版次或不完整上传，应结合作者、摘要与文件信息选择。

## 网盘分享、磁链和种子

点击下载结果中的「解析下载」会识别普通链接、正文纯文本链接、只读复制框，以及常见迅雷包装链接。也可以把整段分享文本（含提取码）、`magnet:?…` 或 `.torrent` 地址粘贴到「读取指定页面或下载地址」。分享卡片中的提取码支持复制，识别到的百度分享码会附在链接中。对于 `?pwd=8888解压码：8888` 或 `?pwd=8888解压密码：9999`，只保留 `?pwd=8888`；链接中明确的提取码优先，解压密码不会被当作网盘提取码。

网盘识别包括百度网盘、夸克、阿里云盘、UC、天翼、123 云盘、蓝奏云、Google Drive、OneDrive、Dropbox 和 PikPak。这里的“识别”是将分享链接和提取码显示为资源卡片，不代表这些平台的全部账号、会员下载或私有接口已经逐个验证。

- **网盘**：「尝试解析文件」读取当前会话可见的文件直链；没有直链时使用「在应用内打开」。在应用内网盘窗口完成提取或登录，再点击原网页提供的书籍下载按钮，文件会自动进入栖读下载队列，ZIP、RAR、7Z 压缩包同样支持。支持保留 Cookie、POST 请求和浏览器生成的 Blob 文件。工具栏可复制或填入提取码、读回当前页文件、返回下载结果；不会代替用户提交登录表单。取消或失败后用「重新打开网盘」重新取得下载地址，分享码会保留。
- **磁链 / 种子**：「解析文件列表」读取元数据，展示文件名和大小，可按名称筛选。支持 BitTorrent v1 及包含 btih 的混合磁链、HTTP(S) `.torrent` 地址；先解析文件列表，再点击具体书籍的「下载」。无需另装迅雷或其他客户端。纯 v2 磁链暂不支持。
- **传输与保存**：沿用统一队列，可取消、查看进度、另存或入架。磁链显示连接数和速度；无节点时解析最多等待 90 秒，传输连续 90 秒无进展时报告失败。相同种子的多个文件按顺序传输，避免重复任务冲突。应用关闭后保留任务与已解析的文件列表，未完成文件需要重试。

支持 EPUB、PDF、TXT 及 ZIP、RAR、7Z，每个文件不超过 100 MB；种子元数据不超过 5 MB，文件列表不超过 2000 项。压缩包下载后提供「另存文件」，需要自行解压后再导入其中的书籍；当前不自动解压或处理压缩密码，也不会将压缩包直接入架。升级前已解析过的种子会更新文件格式信息，使其中的压缩包可以选择下载。其他书籍格式及客户端安装程序不作为下载文件接收。网站登录、验证码、订阅、分享失效及客户端专用下载仍由原站决定，不能保证所有分享都能直接下载。磁链需要可用节点或 Web Seed；下载期间按 BitTorrent 协议交换分片，上传上限 16 KB/s，完成后停止做种。

磁链引擎为独立运行的 aria2 1.37.0，只在使用磁链功能时启动。包内 `resources/aria2/` 提供未修改的官方 Windows 引擎、GPL 许可证、作者信息、SHA-256 来源记录和上游源码压缩包。构建脚本 `scripts/download-engine.mjs` 校验固定发行文件，运行时不会下载额外引擎。

## 自定义下载站

打开「管理下载站点」→「添加下载站点」，将搜索链接里的关键词替换为占位符：

```text
https://example.org/search?q={query}&format={format}
https://example.org/find/{title}?author={author}
```

- `{query}`：书名与选中的作者；类型为「搜索引擎」时增加格式和下载关键词。
- `{title}`：书名。
- `{author}`：勾选「同时匹配作者」时填入，否则为空。
- `{format}`：EPUB、PDF、TXT、ZIP、RAR、7Z；「压缩包」筛选时为中文“压缩包”，全部格式时为空。

「预览结果」直接显示解析出的书目。结构特殊时展开「自定义结果解析规则」，设置条目、标题、链接、简介和下一页的 CSS 选择器，例如 `.book-item`、`h3`、`h3 a`、`.description`、`a.next`。配置只读取文字和链接。

只接受完整 HTTP(S) 地址，最多保存 50 个来源。中文、`&`、`+` 等会编码处理。支持编辑、启停、删除、撤销删除；「补回内置入口」仅补回缺少的来源。所有配置随完整 `.qidu` 备份保存，升级保留已有的启停和删除选择。

## 本地下载记录

- 最多同时传输两个文件，每个文件上限 100 MB，最多保存 100 个任务；可清理旧记录后继续下载。
- 下载复用栖读站点会话。文件通过流写入本地缓存，完成后才可入架或另存。取消、超时、失败会清理不完整文件。
- 拒绝网页/验证响应冒充文件，检查 PDF 标识、EPUB 的 ZIP 与 mimetype、TXT 文本特征及 ZIP/RAR/7Z 文件标识。不会执行下载内容中的程序。
- 退出应用会停止未完成的任务；重启保留记录，普通文件和磁链点击「重新下载」从头下载；网盘使用「重新打开网盘」重新取得有效地址，不自动恢复网络传输。
- 下载缓存不属于书库备份；加入书架后，文件才随 `.qidu` 完整备份保存。下载队列仅在桌面版提供。

## 验证

```sh
pnpm typecheck
pnpm test
pnpm test:downloads
pnpm test:resources
pnpm test:search-session
pnpm check:downloads
```

`test:downloads` 使用隔离资料目录和本地 HTTP 服务，实际传输 TXT、EPUB、PDF，验证会话、重定向、中转解析、下载进度/取消/重试、校验、另存、入架去重和重启。搜索目录使用确定的测试响应；检查外部浏览器调用次数为零。

`test:resources` 使用隔离资料目录和本地测试服务器，验证紧贴解压码的百度 pwd 规范化、分享提取码、Cookie、POST 票据、Blob 下载、取消与重新打开、文件入架、种子文件选择、磁链真实传输、压缩包格式筛选、ZIP/RAR/7Z 下载与另存、无扩展名压缩包识别和重启恢复；`.torrent` 和文件字节实际经过 aria2。单元测试还通过本地真实 BitTorrent 节点验证不带 xs 的磁链元数据交换。网盘主机入口使用受控页面，因此这些测试不等同于各平台真实账号的下载可用性测试。

`check:downloads` 是手动运行的实网检查，记录各来源当前可用性，并将一本 Project Gutenberg 公版 EPUB 下载到隔离测试资料目录、加入测试书架。运行前需要构建应用；设置 `QIDU_PACKAGED_CHECK=1` 可检查发布目录。实测结果见 [验证记录](验证记录.md)。

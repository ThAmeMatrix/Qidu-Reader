# 栖读 · Qidu Reader

一个本地优先的桌面阅读器。为 TXT、EPUB、PDF、网页和 Markdown 提供统一的书架、安静的阅读界面，以及属于自己的书评和摘录。

![书架](docs/screenshots/library.png)

## 直接运行

Windows x64 用户可双击 `release/Qidu-Reader-1.7.0-Windows.exe`，无需安装 Node.js，本地阅读无需账号。便携程序首次启动会解压到临时目录，可能需要几秒。

也可直接运行 `release/win-unpacked/栖读.exe`。此目录下的其他文件是运行所必需的，不要只移动其中的 exe。

## 功能

- **本地阅读缓存**：下载入口自动追踪到具体文件；网盘自动尝试提取码、文件选择和网页下载，遇到登录或验证在应用内继续。选择「加载到本地」才加入下载队列，TXT/EPUB/PDF 完成后绑定原作品，收藏可直接打开本地正文。详情或设置可清空缓存，真实删除文件并保留收藏、书评和进度。
- **百科概述**：作品详情内查询百度百科、维基百科，展示概述、来源词条与获取日期，可改关键词区分同名作品；成功结果缓存七天。百科受限时尝试公开索引摘要，并明确标注。
- **网盘与磁链下载**：识别页面和粘贴分享文本中的网盘链接、提取码、磁链和 `.torrent`。网盘可在应用内提取或登录，解析得到的文件等待用户选择后进入队列；磁链先展示文件列表，再选择 EPUB/PDF/TXT 或 ZIP/RAR/7Z 下载。支持压缩包汇总与单格式筛选，ZIP、RAR、7Z 下载后自动解压书籍并替换对应作品资源，加密包可填写解压密码重试。下载引擎随桌面版提供，详见 [下载查找说明](docs/下载查找说明.md)。
- **站内查找与下载**：书籍卡片、在线详情和本地详情都可查找下载版本。汇总 Internet Archive、Project Gutenberg、搜索引擎、书格、Standard Ebooks、中文维基文库及自定义站点的结果；详情页和中转页在当前界面继续解析，不打开外部浏览器。EPUB/PDF/TXT 与 ZIP/RAR/7Z 直接下载到本地，显示进度，支持取消、重试、另存和一键入架。支持来源/格式筛选、作者匹配、分页、自定义 CSS 解析与配置备份。站点验证、访问限制和无结果分别提示，详见 [下载查找说明](docs/下载查找说明.md)。
- **在线找书**：内置优书、起点、纵横、国家图书馆、哔哩轻小说、Novelia、番茄小说和刺猬猫。聚合搜索、来源筛选、分页、详情、收藏入架；支持添加/编辑/启停/删除自定义站点、GET/POST 搜索、CSS 解析规则及配置导入导出。搜索复用站点窗口的登录状态，支持登录后重试与自动加载动态网页。1.2.0 自动添加两个新源，保留启停、自定义与删除选择。刺猬猫搜索和详情已通过实网检查；番茄已适配接口与动态结果，但本次官网搜索接口返回空响应，应用会提示暂不可用。优书支持打开搜索引擎查找公开书页，站内搜索仍需登录。各站点当前实测情况见 [搜索站点说明](docs/搜索站点说明.md)。
- **收藏管理**：书籍爱心按钮可再次点击取消，书架提供「我的收藏」筛选；阅读器书签支持再次点击或 Ctrl D 取消，侧栏可删除书签与摘录。
- **私人书架**：批量导入、拖放导入、重复文件识别、书名/作者搜索、网格与列表、阅读状态、排序、格式筛选、自定义书单。
- **TXT**：UTF-8、GB18030/GBK、UTF-16 BOM 编码识别，中英文章节识别，长文分段。
- **EPUB**：读取标题、作者和封面，保留书籍排版、目录、分页与 CFI 续读；书内脚本被禁用。
- **PDF**：本地 PDF.js 渲染、页面缩放、页码跳转、文字选择、文字层搜索。字体、CMap 和解码资源随应用打包。
- **网页与文档**：导入 HTML、Markdown；桌面版支持从公开 HTTP/HTTPS 网页提取正文并离线保存。提取结果去除脚本、表单和外部图片。
- **快捷阅读与目录**：右上角一键切换日间/夜间，阅读界面同步切换并保存。下载完成可直接点「立即阅读」；TXT 扩展中英文与编号章节识别，HTML/Markdown 按标题分章，EPUB 缺目录时从正文生成，PDF 优先使用内置目录、否则后台识别章标题。扫描 PDF 仍按页阅读。
- **舒适阅读**：纸间/晴日/夜读/青苔四种主题，宋体/黑体、字号、行距、宽度与专注模式。
- **阅读记录**：自动续读、书签、文字摘录及想法、按书筛选和 Markdown 导出。
- **私人书评**：1–5 星评分、标题、长文本书评、编辑和删除。书评不会发布到网络。
- **阅读足迹**：阅读时间、最近一周图表、每日目标和读完数量；仅记录窗口在前台且两分钟内有操作的阅读时间。
- **本地资料**：IndexedDB 保存手动导入内容和书架记录，下载作品关联磁盘上的单份文件；设置页支持 `.qidu` 完整备份和事务式恢复。

内置的六本书是**原创导读示例，不是原著全文**，便于首次打开时体验功能。正式阅读请导入自己的书籍文件。

## 使用方式

0. 「发现好书」输入书名或作者；「管理搜索站点」可添加网站。搜索结果可查看详情、加入书架和取消收藏。在线书目保存资料与原站链接，不会自动下载整本正文。
   需要文件时点击「下载方案」，在当前界面检查结果并选择格式下载。选择「加载到本地」，支持的书籍下载完成后自动关联作品并加入书架；右上角「下载」可随时查看任务。
1. 点击「导入书籍」，选择文件、拖入文件，或切换「网页链接」。
2. 点击封面进入阅读。左侧可以打开目录、查找和本书收藏；右上角可以添加或取消书签、调整样式、写书评。
3. 选中正文，添加想法并保存摘录。阅读位置和样式会自动保存。
4. 书籍卡片上的 `···` 打开详情，可以调整状态、收藏到书单或移出书架。
5. 在偏好设置中定期导出完整备份。恢复备份会在确认后替换当前资料。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl K | 搜索书架 |
| Ctrl O | 导入文件 |
| Ctrl F | 书内查找 |
| Ctrl D | 添加 / 取消阅读书签 |
| ← / →、PageUp / PageDown | 前后翻页 |
| Esc | 收起浮层/侧栏，退出专注或返回书架 |

## 开发

需要 Node.js 22.12+ 与 pnpm。项目已提供锁文件。

```sh
pnpm install
pnpm desktop:dev
```

浏览器预览：

```sh
pnpm dev
```

打开 `http://127.0.0.1:5173`。浏览器预览和桌面版的本地数据相互独立。网页导入在浏览器中受目标网站 CORS 限制；桌面版通过受限 IPC 获取正文。在线找书在本地开发服务中使用同一受限代理；站点窗口、动态页面读回及下载队列在桌面版提供。

```sh
pnpm typecheck
pnpm test
pnpm test:e2e
pnpm test:discovery
pnpm test:search-session
pnpm test:new-sources
pnpm test:downloads
pnpm test:resources
pnpm test:local-cache
pnpm test:reading-upgrade
pnpm check:downloads # 可选：联网检查来源，并下载一本公版 EPUB 到隔离测试资料目录
pnpm check:sources # 可选：联网检查当前站点状态
pnpm dist
pnpm test:packaged
```

`pnpm dist` 生成 Windows x64 便携可执行文件。`pnpm pack` 生成完整免安装目录。构建会复制 PDF 所需的本地字体、CMap、WASM 资源，并准备固定版本的 aria2 引擎；首次构建需访问 GitHub 下载官方发行文件，校验 SHA-256 后缓存于 `vendor/aria2/`。发行包附带引擎许可证、来源记录和上游对应源码，位于 `resources/aria2/`。

端到端测试运行独立的隐藏 Electron 实例，使用专用测试资料目录，不接触用户书架。测试生成中文 TXT、EPUB、三页 PDF、HTML 和 Markdown，验证完整交互并在 `test-results/` 保存截图和报告。

发布包测试会短暂显示一个独立测试窗口，检查实际可执行文件及本地资源。详见 [验证记录](docs/验证记录.md)。

## 结构

```text
electron/             桌面窗口、受限文件选择、网页获取和 preload
src/components/       书架、书评、摘录、阅读足迹和设置
src/components/reader/ TXT/HTML、EPUB 和 PDF 阅读引擎
src/lib/              导入、清洗、IndexedDB、备份与示例
scripts/              开发、资源准备、图标生成、打包
tests/                导入/存储测试与独立桌面端到端测试
```

技术：React、TypeScript、Vite、Electron、epub.js、PDF.js、Mozilla Readability、DOMPurify、JSZip。

## 数据与边界

- 所有书籍与记录保存在本机应用数据目录；Windows 通常为 `%APPDATA%/栖读/`。删除应用数据目录会删除书架，请先导出备份。
- 网页内容仅在用户主动导入链接时获取，不使用第三方正文代理。应用不提供账号、遥测、云同步或公开书评服务。
- 单文件最大 100 MB，每次最多导入 30 本；网页正文上限 8 MB，20 秒超时。
- 不支持 DRM 加密 EPUB；加密 PDF 请先解锁后导入。扫描 PDF 可按原页查看，但没有 OCR，不能搜索或摘录扫描图像中的文字。
- 需要登录、付费权限或 JavaScript 动态加载的网页可能无法提取正文，可在浏览器中保存 HTML 后导入。
- HTML/网页采用安全的正文阅读模式，保留文字和基本排版；远程图片、脚本、交互表单不加载。
- 当前交付为 Windows x64 便携版，未进行代码签名。Electron 架构可扩展至 macOS/Linux，但这些平台未打包验证。
